# 밸런스 시뮬레이터 (tools/sim.js) 운영 가이드

실제 게임 코드를 화면 없는 브라우저에서 돌리고, 사람처럼 판단하는 봇이 플레이한다. 렌더링 없이 `engine.update()`만 고정 dt로 돌려 실제보다 수십 배 빠르다.

## 돌리기
```bash
node tools/sim.js [판수/영웅=6] [최대웨이브=150]           # 영웅 3명 동시(페이지 3개)
SIM_HEROES=eevee node tools/sim.js 1 30                      # 빠른 동작 확인 (약 40초)
SIM_STRAT='{"boss":"none"}' node tools/sim.js 4 150         # 전략 하나만 바꿔 비교
SIM_DEBUG=1 ...                                              # 웨이브별 [웨이브, 골드, 타워, 보관함, 필드 적] 기록 출력
```
- 시간: 4판 × 3영웅, 150웨이브 ≈ 30~40분. 비교는 **같은 판수로 변경 전/후 2번**, 결과 파일은 `tools/sim-result.json` (커밋 안 함)
- 숫자는 **절대값이 아니라 변경 전후 비교용**. 판수 4는 오차가 크니 결론은 차이가 클 때만

## 출력 읽기
- 판마다: 도달 웨이브 · 데미지 상위 3 · 보스 소환/처치/보스 골드 · 메가(★) · 먹이 횟수 · 최고★ · 확정진화 · 레시피 · 카드 선택/건너뜀 · 지출 상위 4
- 요약: 영웅별 평균/중앙/최소/최대 · 사망 웨이브 분포(10단위) · 평균 지표 · 지출 비중 · MVP 빈도
- 건강한 판의 기준(현재 목표): 영웅 데미지 비중 20~25% · 사망 분포가 한쪽 벽에 몰리지 않음 · 지출이 한 항목 70% 이상 독식하지 않음

## 봇 전략 (사용자 실제 플레이 방식 기준)
| 영역 | 규칙 | 설정(P) |
|---|---|---|
| 보스 | 쿨마다 열린 최고 티어 소환, 필드 1마리로 계산되니 쌓아두고 강해지면 처치 | `boss: max/low/none` |
| 주문 | 쿨마다 그물망·훈련소 (적 5+) | `spells: always/danger` |
| 영웅 | 스킬 쿨마다, 거다이맥스, 스킬포인트 싼 것부터, 변신 아이템 즉시, 이브이는 주력 타입 진화 | — |
| 배치 | 센 타워 = 사거리 안 길이 가장 많은(초입 가중 2배) 자리, 감속·빙결·스턴 상위 3마리 = 길 중간, N웨이브마다 재정렬 | `place, rearrangeEvery, utilSlots` |
| 성장(무료) | 먹이기 ★ 즉시 · ★5 원본 + 스톤 → 바로 메가 · 같은 종 3 확정 진화 · 레시피(뮤/뮤츠)는 자리 부족 + 없을 때만 | — |
| 재료 | 필드 성장 대상과 같은 종·등급, 메가 원본 종은 보관함에 남김(먹이). 나머지는 3개씩 합성해 레전드까지 | — |
| 골드 | 후보마다 (늘어나는 DPS ÷ 비용) 비교: 뽑기·타입강화·기술머신·이상한사탕·부지 확장. 이자 300 저축(필드 100+면 0) | `interest` |
| 뽑기 | 초반 일반 뽑기, `tenFromWave` 이후(또는 자리 다 참) 900 모아 10연. 위험하면 바로 일반 | `tenFromWave` |
| 위험 | 필드 150+ 대피시키기, 175+ 몬스터볼 | — |
| 카드 | 등급 + 주력 타입 일치 점수, 점수 2 미만이면 건너뛰기(골드, 적응 없음) | — |

## 게임 규칙이 바뀌면 봇도 고치기 (체크리스트)
1. **새 아이템·상점 항목** → 골드 쓰기 후보(`C.push`)에 `{k, cost, v}` 추가. `v`는 '늘어나는 DPS' 어림값 (예: 타워 하나 강화면 `tdps(t) × 증가율`)
2. **합성·진화 규칙** → '무료 성장' 블록과 `keep()`(재료로 남길 조건)
3. **보스·웨이브 규칙** → 보스 소환 블록, 사망 판정(`onGameOver`), 웨이브 진행(`sendWave` on idle)
4. **새 선택 창(오버레이)** → 봇 맨 앞 '선택 창' 블록에서 고르기 규칙 추가. 처리 안 하면 창이 계속 떠 있어 진행이 막힘 → 정리 목록(`querySelectorAll(...).remove()`)에도 추가
5. **영웅 스킬·변신 추가** → '영웅' 블록
6. **새 지표가 필요하면** → `ST`에 카운터 추가 후 출력 줄에 표시
7. 고친 뒤 `SIM_HEROES=eevee node tools/sim.js 1 30`으로 오류 없는지 확인(약 40초) → 본 비교
